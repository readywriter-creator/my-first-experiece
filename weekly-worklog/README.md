# 총무부 주간업무일지

기존 **주요업무현황** 양식(구분 · 담당자 · 업무단위 · 업무계획 · 진행상황 · 완료예정일 · 진행률 · 비고)을 그대로 쓰면서, 쌓인 기록에서 **경력기술서 · 교회 연간보고 · 자기평가서 · 자격/학업 지원서** 초안을 바로 만드는 웹앱입니다.

- 앱 주소(비공개, 본인만 열람): https://claude.ai/artifact/EhN5qGHDUxik8EUEdZ69Ey
- 원본 파일: `weekly-worklog/index.html` (이 파일을 수정한 뒤 같은 주소로 다시 게시)

## 핵심 요약

| 항목 | 내용 |
|---|---|
| 사용 범위 | 1단계: 본인 1인용 (다른 사람은 링크가 있어도 기록이 보이지 않음) |
| 저장 위치 | Claude 저장소. 같은 계정으로 로그인해 연 기기에서는 같은 기록 (기기마다 `사용법` 맨 위 문장으로 확인) |
| 휴대폰 | 진행률 숫자를 눌러 바로 고치기, 위쪽 `업무 추가`, 전체 화면 편집, 세로 목록 주간보고 |
| 주간 작성 시간 | 매주 5~10분 (미완료 업무는 버튼 한 번으로 이월) |
| 엑셀 연동 | 기존 엑셀 가져오기, 주간보고·전체 기록 엑셀 저장 |
| 포트폴리오 | 4종 문서 초안 자동 생성, 기록에 없는 수치는 `[수치 확인 필요]`로 표시 |

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 이번 주 | 업무 추가·수정, **진행률 숫자를 눌러 바로 고치기**(진행률 선택, 한 일 한 줄, 완료 시 성과 한 줄), **지난주 미완료 업무 가져오기**, 전체·진행중·지연·완료·예정으로 걸러 보기, 처음 쓰는 순서 4단계 |
| 주간보고 | 기존 8개 열 그대로의 보고서 화면(결재란 포함), 다음 주 계획 자동 정리, 특이사항 메모(앱을 닫거나 다른 앱으로 넘어갈 때도 저장), **엑셀 저장 / 표 복사** |
| 누적 기록 | 여러 주에 걸친 같은 업무를 하나로 묶어 표시, 구분별 완료 현황, 성과 미기록 업무 확인 |
| 포트폴리오 | 문서 종류 · 기간 · 범위 · 분야 · 지원 대상 선택 → Claude가 초안 작성 → 수정 후 복사 또는 .md 저장 |
| 설정 | 부서명 · 본인 이름 · 주 시작 요일 · 결재란 · 구분/역량 목록 수정, 엑셀 가져오기, 백업·복원 |
| 사용법 | 위쪽 `사용법`(휴대폰은 다른 탭의 저장 상태 글자)을 누르면 열림. 저장 상태 확인, 매주 순서, 휴대폰·다른 컴퓨터·공용 컴퓨터에서 여는 법, `앱 주소 복사` |

## 매주 사용 루틴 (5~10분)

1. **월요일(또는 주 시작일)**: `이번 주` → `지난주 미완료 N건 가져오기` → 새 업무는 `업무 추가`
2. **주중**: 휴대폰에서 진행률 숫자를 눌러 진행률을 고르고 한 일을 한 줄 덧붙임 (다른 칸까지 고치려면 행을 누름)
3. **완료 시**: 진행률 `완료`를 누르면 ‘커리어 기록’ 칸이 자동으로 열림 → **정량 성과 한 줄**만이라도 입력
4. **주말**: `주간보고`에서 특이사항 입력 → `엑셀로 저장` 또는 `표 복사` 후 결재 상신
5. **분기 · 연말**: `포트폴리오`에서 필요한 문서 초안 생성

|---|---|---|
| 구분 | 기본 8열 | 시설관리, 방송·미디어, 재정·회계 등 (설정에서 수정) |
| 담당자 | 기본 8열 | 설정의 본인 이름이 자동 입력 |
| 업무단위 | 기본 8열 | 결과물이 보이는 단위로 (예: “본당 냉난방기 동절기 점검”) |
| 업무계획 / 진행상황 | 기본 8열 | 계획 = 하려는 일, 진행상황 = 실제로 한 일 |
| 완료예정일 | 기본 8열 | 지나도 100% 미만이면 **지연**으로 자동 표시 |
| 진행률 | 기본 8열 | 0~100%, 100% = 완료 |
| 비고 | 기본 8열 | 협조 요청, 특이사항 |
| 역할 | 커리어 | 주도 / 협업 / 지원 |
| 정량 성과 | 커리어 | **금액 · 시간 · 건수 · %** 중 하나 이상 (예: “견적 비교로 120만원(8%) 절감”) |
| 역량 태그 | 커리어 | 예산관리, 업체·계약관리, 안전관리, 장비운영 등 (복수 선택) |
| 증빙 자료 | 커리어 | 결재문서 번호, 견적서, 사진 등 — 지원서의 증빙 목록이 됨 |
| 배운 점 | 커리어 | 한 줄 회고 — 자기평가서의 ‘성장 · 개선’ 근거 |
| ★ 대표 업무 | 커리어 | 경력기술서에 반드시 넣을 업무 표시 |

## 포트폴리오 문서 4종

| 문서 | 독자 | 구성 | 기본 포함 범위 |
|---|---|---|---|
| 이직용 경력기술서 | 교회 밖 채용 담당자 | 경력 요약 → 분야별 STAR 성과 → 핵심 역량 → 지원 직무 연결 | 완료 업무 |
| 교회 연간 업무보고 | 당회 · 제직회 | 개요 → 분야별 실적 표 → 주요 성과 → 미완료 과제 → 차기 제안 | 전체 |
| 인사평가 · 자기평가서 | 평가자 | 목표 대비 실적 → 강점 → 개선 계획 → 다음 기간 목표 | 전체 |
| 자격 · 학업 지원서 | 심사위원 | 실무경력 요약 → 대표 경험 → 지원 분야 연관성 → 증빙 목록 | 완료 업무 |

**작성 원칙(프롬프트에 고정)**: 입력된 사실만 사용 · 없는 수치는 `[수치 확인 필요]` · 성도 개인정보 제외 · 문서 끝에 “보완이 필요한 기록” 3~5개 제시.
Claude 직접 생성이 막힌 화면에서는 `요청문 복사` → Claude 대화창에 붙여넣기로 같은 결과를 얻을 수 있습니다.

## 디자인 기준

화면은 디자인 스킬 [Taste](https://github.com/Leonxlnx/taste-skill)의 앱 화면 규칙과 Anthropic 공식 [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design) 지침으로 다시 만들었습니다. 고쳐 쓸 때도 아래 기준을 지켜 주세요.

| 기준 | 내용 |
|---|---|
| 스타일 | 무채색 장부형(achromatic-ledger). 화면 틀은 검정·회색만, 색은 데이터에만 |
| 색 | 진행률 막대에만 파랑 하나, 빨강은 지연된 사실에만, 주 버튼은 검정 하나 |
| 글꼴 | 한글 Noto Sans KR, 숫자·영문 Geist(고정폭 숫자). 글꼴은 이 두 가지만 |
| 표 | 줄과 정렬로 구분(줄무늬·색 머리줄 없음), 숫자는 오른쪽 정렬, 빈 값은 회색 대시 |
| 금지 | 그라데이션, 카드 그림자, 아이콘 박스, 이모지·기호 아이콘, 제목 위 작은 라벨, 색 알약 배지 남발 |
| 휴대폰 | 메뉴는 하단 탭 막대, 위쪽 막대에 `업무 추가`, 표는 두 줄 목록, 편집 창은 전체 화면(저장은 머리에), 누르는 곳은 모두 44px 이상 |

## 처음 사용할 때

1. 앱을 열면 **예시 데이터 9건**이 보입니다(담당자가 ‘예시’로 표시됨). 가져오기 · 지연 · 포트폴리오를 한 번 눌러 본 뒤 `예시 지우기`를 누르세요.
2. `설정`에서 **본인 이름 · 결재란 · 주 시작 요일**(월요일 휴무면 화요일)을 먼저 저장하세요.
3. 기존 ‘주요업무현황’ 엑셀이 있으면 `설정` → `엑셀 또는 CSV 파일 선택`으로 한 번에 가져옵니다. 병합된 구분 칸, 60% · 0.6 · “60%” 형식의 진행률, 날짜 셀을 모두 인식합니다. CSV는 UTF-8로 저장해야 한글이 깨지지 않습니다.

| 기기 | 여는 법 | 확인 정도 |
|---|---|---|
| 휴대폰 Claude 앱 | claude.ai/mobile 에서 앱 설치(iOS 18+, Android 8+) → 같은 계정 로그인 → 메뉴의 Artifacts | 앱에서 아티팩트 열기: 공식 확인. 앱 안의 저장 기능: **확인 필요**(화면 문장으로 확인) |

| 사내 네트워크 | 화면이 비면 claude.ai와 claudeusercontent.com 허용 요청 | 공식 확인 |

## 주의사항

- **성도 개인정보 · 헌금 개별 내역은 입력하지 않습니다.** 재정은 사업 단위 금액만 기록합니다.
- 앱은 기본 비공개입니다. 공유 여부는 앱 화면의 공유 메뉴에서 본인이 직접 정합니다.
- 한 달에 한 번 `설정` → `백업 파일 받기` 또는 `누적 기록` → `전체 기록 엑셀로 저장`을 권장합니다.
- 포트폴리오 생성에는 본인 Claude 사용량이 쓰이며, 처음 한 번 허용 여부를 묻습니다.
- 공유 설정은 claude.ai 웹이나 데스크톱 앱에서만 바꿀 수 있습니다(모바일 앱에서는 불가).
- 앱을 고쳐 다시 게시할 때는 먼저 백업을 받고, **같은 주소로** 게시합니다. 새 주소로 게시하면 저장소가 비어 있는 새 앱이 됩니다.
